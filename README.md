# LLM-Assisted Dynamic Attack Scenario Generation for Hybrid Cyber Ranges

## Overview

This project presents an AI-driven framework for generating realistic cyber attack scenarios using Large Language Models (LLMs) within hybrid cyber range environments.

The framework supports:

- Automated attack scenario generation
- MITRE ATT&CK mapping
- Multi-stage attack path creation
- Dynamic/adaptive attack generation
- Scenario evaluation and scoring
- Dataset generation (300–500 scenarios)
- Attack graph visualisation
- Experiment automation
- Research reproducibility

---

## Research Objectives

The primary goals are:

1. Generate realistic multi-stage attack scenarios
2. Improve cyber range adaptability
3. Evaluate realism and diversity of generated attacks
4. Create reproducible research datasets
5. Support AI-assisted cyber security experimentation
